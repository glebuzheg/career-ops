# Открыть Career Ops на своём компьютере

Облачный запуск в сессии проверен, но его `127.0.0.1:3000` не является адресом
вашего компьютера. Встроенный проброс порта у текущей среды отсутствует.
Ниже — запуск того же интерфейса из вашего форка на своём компьютере.

## Первая установка

Установите Git и Node.js 24 LTS. Откройте обычный терминал или PowerShell
и выполните команды по очереди:

```sh
git clone --branch feat/russian-job-sources https://github.com/glebuzheg/career-ops.git
cd career-ops
npm install --ignore-scripts
npm --prefix web ci --ignore-scripts
npm --prefix web run build
npm --prefix web start
```

Откройте <http://127.0.0.1:3000> в браузере **этого компьютера**. Оставьте
терминал открытым; `Ctrl+C` остановит сервер. По умолчанию он принимает
соединения только с вашего компьютера. Аккаунт GitHub для чтения публичного
форка не нужен. Ключ AI-провайдера или установленный AI CLI понадобится для
оценки вакансий, но не для открытия интерфейса.

`--ignore-scripts` здесь пропускает скачивание браузера Playwright при
установке. Если понадобится генерация PDF, отдельно выполните из корня:

```sh
npx playwright install chromium
```

## Повторный запуск

В терминале перейдите в папку `career-ops` и выполните:

```sh
npm --prefix web start
```

Если порт 3000 занят:

```sh
npm --prefix web start -- -p 3001
```

Тогда адрес интерфейса — <http://127.0.0.1:3001>.

## Российские источники

Откройте [настройку источников](RUSSIAN_SOURCES.md). Для новой установки есть
`templates/portals.russia.example.yml`; в существующую конфигурацию переносите
нужные записи вместо замены файла. Python в примере — демонстрационный запрос,
его нужно заменить своей специальностью. CV и предпочтения не предзаполнены.

Хабр Карьера проверен на живых данных. HH из облачной среды возвращал 403;
его доступность на вашем компьютере нужно проверить. SuperJob требует ключ
приложения, Hirify — фактический MCP endpoint и авторизацию. Не публикуйте
ключи в GitHub или чате; храните их в своём `.env`.

## Если нужен сервер/VPS

Для запуска на другом сервере потребуется его адрес и разрешённый способ
доступа. Рекомендуемый способ личного доступа — SSH-туннель к серверу,
на котором приложение остаётся привязанным к `127.0.0.1`:

```sh
ssh -N -L 3000:127.0.0.1:3000 user@your-server
```

После запуска приложения на сервере и туннеля на своём компьютере откройте
<http://127.0.0.1:3000>. Само приложение не имеет входа по паролю: для доступа
по домену нужны отдельная аутентификация, HTTPS и постоянное хранилище файлов.
Один только публичный URL не заменяет эти настройки.
